# Codex Stage F — 간소화 생성 + 프로젝트 설정 + 대시보드 그래프 + 데모 데이터

당신은 PacePM 구현 매니저다. 기존 코드를 파악하고 아래를 구현하라. 완료 기준: `apps/api/.venv/bin/python -m pytest` 전건 통과(기존 81건 회귀 없음), `cd apps/web && npm run build` 성공.

## 1. 프로젝트 생성 간소화

1-1. 백엔드: `projects`에 `owner`(String(100), nullable) 컬럼 추가. `ProjectCreate`를 **name만 필수**로 변경 — owner 선택, 나머지는 기본값(start_date=오늘, target_date=오늘+30일, work_days=[0,1,2,3,4], daily_capacity_hours=4.0, buffer_ratio=0.2, excluded_dates=[]). 기존 검증(target>=start 등)은 값이 주어질 때만. ProjectOut/ProjectPatch/shared-types에 owner 반영. PATCH로 owner 수정 가능.
1-2. 프론트 `/projects/new`: 기본 화면을 **초간단 폼(프로젝트 이름 + 담당자[선택], 버튼 1개)** 으로 교체. 생성 즉시 `/projects/[id]/today`로 이동. 화면 하단에 작은 링크 2개로 기존 진입 유지: "AI 대화로 자세히 만들기"(guided), "상세 폼으로 만들기"(manual) — 쿼리 파라미터(?mode=guided|manual)로 전환.
1-3. 프로젝트 목록 카드에 담당자 표시(있을 때만).

## 2. 프로젝트 설정 화면 (필수사항 없음)

2-1. 새 라우트 `/projects/[id]/settings`: 프로젝트명, 담당자, 설명, 시작일, 목표일, 작업 요일, 하루 가용시간, 버퍼, 제외 날짜를 언제든 수정·저장(PATCH). 필수 표시 없음, 저장 성공 피드백 표시. project-nav에 "설정" 탭 추가.
2-2. 기간·가용시간 변경 시 "일정을 다시 생성해야 반영됩니다" 안내 문구.

## 3. 대시보드 그래프 (plan 페이지 대시보드 카드 아래 섹션)

새 컴포넌트 `components/progress-chart.tsx` — 외부 라이브러리 금지, 인라인 SVG + Tailwind만.

3-1. 탭: 일간 / 주간 / 월간. 데이터 소스는 이미 로드된 schedule snapshot placements + tasks.
   - 일간: 날짜별 노드(막대). 주간: ISO 월요일 시작 주별. 월간: 월별.
   - 각 노드 값 = 해당 기간 배정 공수(시간). 막대는 **진행률 채움** 구조: 트랙(배정 총량, 색 #e7edea + 1px #d7e1dd 테두리) 위에 완료 채움(완료 공수 = Σ placement.hours × 해당 task progress/100, 색 #166a58). 오늘/이번 주/이번 달 노드는 아래 축 라벨을 굵게 + 점 표시.
3-2. 디자인 규칙(준수 필수):
   - y축 1개(시간). 이중 축 금지. 그리드는 연한 수평선 3~4개만(#eef2f0), 축 라벨은 잉크색(#71807b) — 데이터 색을 텍스트에 쓰지 않는다.
   - 막대 폭은 가늘게(노드 수에 따라 자동, 최대 28px), 완료 채움 상단만 2px 라운드, 막대 사이 간격 ≥ 2px.
   - 잔여 트랙 색 대비가 낮으므로 **각 막대 위에 달성 % 직접 라벨**(노드 ≤ 14개일 때) 또는 호버 시 항상 표시. 범례: "완료" 사각 스와치(#166a58) + "배정" 스와치(트랙 색) 2개를 차트 우상단에 텍스트는 잉크색으로.
   - 컨테이너는 overflow-x 스크롤 허용(노드 많을 때), viewBox 반응형.
3-3. 호버 툴팁(필수): 노드에 마우스 올리면(투명 히트 영역은 막대보다 넓게, 전체 열 높이) 툴팁 표시 —
   - 헤더: 기간 라벨(예: 8월 6일 (수) / 8월 4일 주 / 2026년 8월), 배정 Nh · 완료 Nh · 달성 N%
   - 본문: 해당 기간 task 목록 — 각 줄에 [✓ 완료 | ○ 진행 중 N% | · 대기] 아이콘/라벨 + task 제목 + 그 기간 배정 시간. 최대 8개 + "외 N개".
   - 툴팁은 잉크색 텍스트, 흰 배경, 그림자, 화면 밖으로 잘리지 않게 좌우 플립. 터치/키보드 접근: 노드에 tabIndex + focus 시 툴팁 표시, aria-label 제공.
3-4. 일정이 없으면 빈 상태("일정을 생성하면 그래프가 표시됩니다" + 일정 생성 버튼으로 스크롤/이동).

## 4. 데모(mock) 데이터 5개

4-1. `apps/api/seed_demo.py` 작성 — venv python으로 실행하면 데모 프로젝트 5개 생성. `python seed_demo.py` (DATABASE_URL 존중, 같은 이름 존재 시 스킵하고 알림 출력).
4-2. 5개 구성(모두 담당자 지정, 오늘 2026-08-06 기준):
   1) "PacePM 베타 출시" (담당 이정현) — 진행 중·정상 페이스: 8/1 시작, 8/31 목표, 업무 8개(의존관계 포함), 4개 완료(완료일 8/1~8/5 분산, actual_hours 기록), 1개 진행 중 60%, 일정 생성됨.
   2) "고객사 A SI 구축" (담당 김서연) — 주의: 완료 2/10, 일부 지연, 진행 중 30%·차단 1개.
   3) "사내 문서 자동화 PoC" (담당 박민준) — 위험: 목표일 임박(8/12), 완료 1/6.
   4) "홈페이지 리뉴얼" (담당 최윤아) — 거의 완료: 완료 7/8, 남은 1개 80%.
   5) "데이터 파이프라인 개선" (담당 이정현) — 막 시작: 오늘 시작, 완료 0/5, 전부 대기.
   각 프로젝트: 업무별 estimated_hours 1~8h 다양, 우선순위 혼합, 완료 업무는 actual_end_date를 지난 작업일에 분산(예측 그래프가 살도록 3작업일 이상), 마지막에 서비스 함수로 schedule 생성(승인 상태 업무만). 그래프에 일간/주간/월간 데이터가 보이도록 기간을 걸쳐 배치.
4-3. README에 데모 시드 실행법 한 줄 추가.
