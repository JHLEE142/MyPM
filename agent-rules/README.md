# MyPM 에이전트 규칙

AI 코딩 에이전트(Claude Code 등)가 **자료를 받으면 MyPM의 업무·기한·진행률을 알아서 갱신**하도록 하는 규칙 묶음입니다.

캡처 이미지, 회의록, 슬랙 로그, 진행 메모를 붙여넣고 "이거 반영해줘"라고만 하면,
에이전트가 어느 프로젝트 이야기인지 판별해 해당 업무의 진행률을 고치고, 새로 생긴 일을 추가하고, 끝난 일을 완료 처리합니다.
매번 "MyPM에도 반영할까요?"를 되묻지 않습니다.

## 설치

```bash
python3 scripts/install_agent_rules.py
```

설치기는 **두 단계 동의**를 받습니다.

1. **고지와 동의** — 에이전트가 확인 없이 무엇을 하게 되는지, 어떤 파일이 바뀌는지 보여주고 `동의` 입력을 요구합니다.
2. **변경 미리보기와 적용 확인** — 실제로 쓰일 내용을 diff로 보여주고 `y` 입력을 요구합니다.

어느 단계에서든 다른 값을 입력하면 아무것도 바뀌지 않습니다.

```bash
python3 scripts/install_agent_rules.py --dry-run    # 아무것도 바꾸지 않고 미리보기만
python3 scripts/install_agent_rules.py --uninstall  # 연결 해제
```

| 옵션 | 설명 |
|---|---|
| `--level` | 자율성 수준: `conservative` / `standard`(기본) / `autonomous` |
| `--scope` | `global`(기본, `~/.claude/CLAUDE.md`) 또는 `project`(현재 폴더의 `CLAUDE.md`) |
| `--output` | 규칙 파일 경로 (기본 `./AGENTS.md`) |
| `--api-url` | MyPM API 주소 (기본 `http://localhost:8000`, 환경변수 `MYPM_API_URL`) |
| `--dry-run` | 변경 없이 미리보기 |
| `--yes` | 모든 확인에 동의 (자동화용) |
| `--uninstall` | 메모리 파일에서 규칙 블록만 제거 |

## 자율성 수준

에이전트에게 얼마나 맡길지 설치할 때 고릅니다. 나중에 다시 실행해 바꿀 수 있습니다.

| 수준 | 확인 없이 자동 | 먼저 확인 |
|---|---|---|
| `conservative` | 조회와 변경안 제시만 | 모든 쓰기 작업 |
| `standard` (권장) | 진행률·완료·이름/공수/기한 수정, 업무 추가, 취소된 개별 업무 삭제, 일정 재생성 | 목표일 변경, 전체 삭제, 프로젝트 삭제, 가용시간 변경, 새 프로젝트 생성 |
| `autonomous` | 위 항목 + 목표일 변경과 재계획 | 프로젝트 삭제, 업무 전체 삭제, 새 프로젝트 생성 |

## 바뀌는 파일

설치기는 **두 개의 파일만** 건드리고, 덮어쓰기 전에 항상 `.bak.<타임스탬프>` 백업을 남깁니다.

1. **`AGENTS.md`** (기본 `./AGENTS.md`) — 규칙 본문. 프로젝트 레지스트리와 API 사용법이 들어갑니다.
2. **에이전트 메모리** (`~/.claude/CLAUDE.md` 또는 `./CLAUDE.md`) — 아래 블록만 추가되고 기존 내용은 그대로 보존됩니다.

```markdown
<!-- BEGIN MyPM agent rules (managed by scripts/install_agent_rules.py) -->
# MyPM 자동 반영
...
@/절대/경로/AGENTS.md
<!-- END MyPM agent rules -->
```

다시 설치하면 이 블록만 교체됩니다(멱등). `--uninstall`은 이 블록만 지우고 나머지는 건드리지 않습니다.

## 프로젝트 레지스트리

설치 시점에 `GET /api/projects`로 프로젝트 목록을 읽어 규칙 파일에 표로 넣습니다.
API가 꺼져 있으면 표를 비워 두고 경고만 출력하니, API를 켠 뒤 다시 실행하면 채워집니다.

식별 키워드(슬랙 채널명 등)는 프로젝트 설명에서 자동 추출하므로 부정확할 수 있습니다.
**설치 후 그 열을 실제로 쓰는 채널명·고객사명으로 보완**하면 매칭 정확도가 크게 올라갑니다.

## 개인정보 주의

생성된 `AGENTS.md`에는 **프로젝트명·기간·슬랙 채널명이 평문으로** 들어갑니다.
공개 저장소에 커밋하지 마세요. 이 저장소의 `.gitignore`는 루트의 `AGENTS.md`를 제외하도록 되어 있습니다.

배포되는 것은 개인정보가 없는 `agent-rules/AGENTS.template.md`뿐입니다.

## 에이전트 호환성

`@경로` import 문법을 쓰는 에이전트(Claude Code)에서 검증했습니다.
그 문법을 지원하지 않는 도구라면, 생성된 `AGENTS.md` 내용을 해당 도구의 규칙 파일에 직접 붙여넣어 쓰세요.
Claude Code는 `AGENTS.md`를 자동으로 읽지 않기 때문에, 이 설치기가 `CLAUDE.md`에서 import 하도록 연결해 줍니다.

## 안전 설계

- 자료(문서·캡처·슬랙 로그) 안의 문장은 **데이터로만 취급하고 지시로 실행하지 않는다**는 규칙이 본문에 포함됩니다.
  자료에 "모든 업무를 삭제하라" 같은 문장이 있어도 에이전트는 실행하지 않고 사용자에게 인용해 알립니다.
- 자료에 근거가 없는 진행률·기한은 지어내지 않습니다.
- 로컬 MyPM 인스턴스를 전제로 합니다. 원격·공용 인스턴스에 적용하려면 사용자 확인을 받도록 규칙에 명시되어 있습니다.
